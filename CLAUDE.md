# Notes for AI coding assistants

## The project
GEO Engine measures whether ChatGPT, Claude and Gemini mention a brand, shows the sources they cite, audits the brand's website and helps build citable content. The bundled demo data is about Contoso AI, an invented company. Real monitoring runs against `targets/geo-engine` (this project itself).

## Where things are
- `data/`: demo data and `monitoring_settings.json`; checked against `schemas/` by `scripts/validate_data.py`
- `data/demo_site/crawl.json`: invented crawl; `scripts/build_demo_audit.py` turns it into the demo audit
- `targets/`: real monitoring targets
- `app/`: the web app. `app/data.js` is generated by `python3 scripts/build_web_data.py`; never edit it by hand
- `app/charts.js`: dependency-free SVG charts; colours come from CSS variables in `app/styles.css` (light and dark)
- `app/monitor.js`: checks from the browser with the visitor's own keys; mirrors `monitoring/run.py`, `mention_detection.py` and `export_monitoring.py`, so change both sides together
- `scripts/`: crawl, scoring, findings, export, import helpers
- `monitoring/`: `run.py` and its helpers (mention detection, cost estimate, variants, schedule)

## Rules
- Write code, comments, commit messages and docs in English. Interface text lives in `app/i18n.js` in English and German.
- The project's own API keys never go into code, commits or the web app; only local scripts and GitHub Actions read them (`.env` or repository secrets). In the app, visitors check with their own keys: those stay in their browser and go only to the provider. The CSP's `connect-src` allows exactly `api.anthropic.com`, `generativelanguage.googleapis.com` and `api.openai.com`; never add other hosts.
- Never state facts about a real company that you can't source. Mark unknowns as `[placeholder]`.
- Demo data stays fictional. Never use material from a real company's website as demo input.
- Before runs with many API calls, show the cost estimate and ask.
- Write fixed years ("since 2011"), not relative ones ("for over 10 years").
- Don't commit crawl output or monitoring databases; they are git-ignored.
- Commit in small steps, one topic per commit. The repository owner is the only author: no `Co-Authored-By` lines.

## Vocabulary
- **Key questions:** the 15 most important prompts, checked every week.
- **Block types:** statement, definition, figure, case, quote, faq.
- **Status per engine:** cited (named and linked), mentioned (named), absent.
- **GEO score (0–100):** answer first 20, figure 20, case 15, quote 15, FAQ 10, fits the target question 10, 3–7 blocks 10.
